# ADR-001: JWT (passport) вместо Keycloak

**Статус:** Принято  
**Дата:** 2026-09-21

## Контекст

Нужна регистрация и авторизация для 2 предзаполненных пользователей.
Keycloak даёт SSO, управление realm, полный lifecycle пользователей, но для min-trello это избыточно.

## Решение

Используем `@nestjs/passport` + `@nestjs/jwt` с bcrypt для хеширования паролей.

## Последствия

- Нет отдельного контейнера Keycloak → меньше ресурсов
- Нет сложной конфигурации realm/client
- Если в будущем понадобится SSO — Keycloak добавляется слоем поверх JWT
- Пароли хранятся в той же БД через Prisma (в таблице User)

## Альтернативы

- **Keycloak** — rejected: overkill для 2 пользователей
- **Auth0** — rejected: внешняя зависимость, платная
- **Session-based auth** — rejected: JWT удобнее для API + WebSocket
