# ADR-007: Recharts для графиков дашборда

**Статус:** Принято  
**Дата:** 2026-09-21

## Контекст

Дашборд требует визуализации статистики (карточки по статусам, просроченные дедлайны и т.п.).

## Решение

Используем **Recharts** с `ResponsiveContainer`.

## Последствия

- Декларативные React-компоненты, сочетается с Tailwind/shadcn.
- `ResponsiveContainer` закрывает адаптивность графиков.
- Небольшой bundle; при необходимости тяжёлых визуализаций можно заменить точечно.

## Альтернативы

- **Chart.js** (+ react-chartjs-2) — rejected: императивный wrapper, хуже ложится на React-дерево.
- **visx / D3** — rejected: избыточная гибкость для типовых графиков.
